# 🤖 GPT Consultant — инструкция по установке и настройке

Привет! Это альтернативная инструкция для **GPT Consultant** — плагина для FunPay Cardinal, который позволяет использовать искусственный интеллект как консультанта в чатах с покупателями FunPay.

Плагин может отвечать на вопросы покупателей, учитывать описание товара и предыдущие сообщения в чате, при необходимости искать дополнительную информацию в интернете и автоматически подбирать стиль ответа.

> Основная инструкция: https://teletype.media/@tinechelovec/GPT-Consultant
> GitHub: https://github.com/tinechelovec/FPC-Plugin-GPT-Consultant

---

# 📌 Что делает GPT Consultant

GPT Consultant умеет:

* отвечать покупателям с помощью AI;
* учитывать описание открытого FunPay-лота;
* учитывать предыдущие сообщения из чата;
* сохранять контекст диалога;
* работать только по специальной команде;
* автоматически отвечать на обычные сообщения;
* самостоятельно решать, нужен ли ответ покупателю;
* искать дополнительную информацию в интернете;
* использовать разные AI-модели;
* автоматически переключаться на резервную модель при ошибке;
* использовать разные стили общения;
* работать через API IO Intelligence;
* вести подробные логи;
* создавать резервную копию настроек;
* обновляться через Telegram-интерфейс.

---

# 🚀 Установка

Для работы нужен установленный **FunPay Cardinal**.

После установки Cardinal:

1. скачайте актуальную версию GPT Consultant;
2. откройте Telegram-бота Cardinal;
3. отправьте:

```text
/menu
```

4. перейдите в раздел **«Плагины»**;
5. загрузите `.py`-файл GPT Consultant;
6. откройте установленный плагин.

Также панель GPT Consultant можно открыть командой:

```text
/gptc
```

# 🔑 API-ключ IO Intelligence

Для работы GPT Consultant понадобится API-ключ **IO Intelligence**.

Откройте:

**⚙️ Настройки → 🔑 API-ключ**

Нажмите:

**✏️ Ввести ключ**

и отправьте API-ключ одним сообщением.

После сохранения в меню появится:

```text
API-ключ: ✅ задан
```

Ключ сохраняется в локальном файле настроек плагина и не записывается напрямую в исходный `.py`-файл.

При необходимости ключ можно удалить кнопкой:

**🗑 Удалить**

# 🎛 Режим работы

В GPT Consultant есть три режима.

Это одна из самых важных настроек плагина.

---

# ⌨️ Обычный

Самый простой и безопасный режим.

Плагин отвечает **только после специальной команды**.

По умолчанию используется:

```text
/qa
```

Например, покупатель пишет:

```text
/qa Какая версия игры?
```

После этого GPT Consultant:

1. получает вопрос;
2. смотрит описание открытого товара;
3. учитывает сохранённый контекст чата;
4. отправляет данные AI;
5. получает ответ;
6. отправляет ответ покупателю.

Если покупатель пишет обычное сообщение без команды, GPT Consultant **не отвечает**, но сохраняет сообщение в контекст.

Благодаря этому следующий вопрос через `/qa` может учитывать предыдущую переписку.

---

# 🔎 Эксперт

Эксперт тоже отвечает только после команды.

Например:

```text
/qa Поддерживается ли эта игра на Steam Deck?
```

Главное отличие от обычного режима — возможность использовать интернет.

Сначала GPT Consultant пытается найти ответ в:

1. сообщении покупателя;
2. предыдущей переписке;
3. описании товара.

Если этих данных недостаточно, плагин может решить, что нужен внешний источник.

Если интернет включён, GPT Consultant выполняет поиск и передаёт найденную информацию AI для формирования ответа.

Этот режим хорошо подходит для товаров, по которым покупатели часто задают технические или справочные вопросы.

---

# 🧠 Всемогущий

Это полностью автоматический режим.

Покупателю уже не нужно писать:

```text
/qa
```

GPT Consultant обрабатывает обычные сообщения самостоятельно.

После каждого подходящего сообщения AI решает:

* ответить покупателю;
* воспользоваться интернетом;
* ничего не отвечать.

Например, покупатель пишет:

```text
Здравствуйте, товар ещё актуален?
```

Плагин может ответить автоматически.

Если покупатель пишет:

```text
Спасибо
```

AI может решить, что дополнительный ответ не требуется.

Если информации недостаточно и вопрос требует внешних данных, плагин может выполнить интернет-поиск.

---

## ⚠️ Команды во «Всемогущем»

В режиме **«Всемогущий»** сообщения, которые начинаются с:

```text
/
```

или:

```text
!
```

игнорируются.

Это сделано для того, чтобы GPT Consultant не реагировал на команды других плагинов и FunPay Cardinal.

---

# 💬 Контекст чата

GPT Consultant сохраняет часть предыдущего диалога.

В контекст попадают:

* сообщения покупателя;
* ручные сообщения продавца;
* предыдущие ответы GPT Consultant.

Это позволяет AI понимать разговор, а не рассматривать каждое сообщение полностью отдельно.

Например:

```text
Покупатель: Эта версия для Steam?

Продавец: Да.

Покупатель: А регион какой?
```

GPT Consultant может учитывать предыдущий разговор при формировании ответа.

---

# 🛒 Описание товара

Если покупатель находится на конкретном FunPay-лоте, GPT Consultant пытается получить информацию о нём.

В AI-контекст могут попадать:

* название товара;
* описание;
* цена.

Это позволяет отвечать на вопросы вроде:

```text
Что входит в комплект?
```

или:

```text
Сколько длится гарантия?
```

если нужная информация действительно есть в описании лота.

Если покупатель не открыл конкретный лот, плагин всё равно может работать по сообщению и истории чата.

---

# ⚠️ GPT Consultant не должен придумывать условия

Если нужной информации:

* нет в описании;
* нет в переписке;
* нет в доступных внешних источниках;

плагин не должен придумывать условия продавца.

Например, AI не должен сам обещать:

* гарантию;
* возврат;
* срок доставки;
* скидку;
* дополнительные услуги,

если такая информация нигде не указана.

---

# 🌐 Интернет

В настройках есть отдельная кнопка:

**🌐 Интернет**

Её можно включить или выключить.

Интернет используется в тех режимах, где AI может решить, что локальных данных недостаточно.

Например, покупатель спрашивает:

```text
Поддерживает ли программа Windows 11?
```

Если в описании товара этого нет, режим **«Эксперт»** или **«Всемогущий»** может выполнить внешний поиск.

Найденные результаты используются как справочная информация.

---

## Если интернет выключен

Если AI понимает, что внешние данные нужны, но интернет отключён, GPT Consultant не выполняет поиск.

В таком случае плагин работает только на основании:

* сообщения;
* истории чата;
* описания товара.

# 🤖 Выбор модели

После добавления API-ключа GPT Consultant может получить список доступных текстовых моделей IO Intelligence.

Откройте:

**🤖 Модель и стиль → 🤖 Выбрать модель**

Плагин покажет список доступных моделей.

Текущая модель отмечается:

```text
✅
```

Можно выбрать другую модель вручную.

По умолчанию плагин использует:

```text
meta-llama/Llama-3.3-70B-Instruct
```

Но список доступных моделей может меняться со стороны API.

---

# 🔄 Обновить список API

Кнопка:

**🔄 Обновить список API**

повторно запрашивает доступные модели у IO Intelligence.

Это полезно, если:

* появилась новая модель;
* старая модель исчезла;
* вы поменяли API-ключ;
* список моделей отображается неправильно.

---

# 🛟 Автоматическое переключение моделей

GPT Consultant умеет автоматически менять AI-модель, если основная временно не работает.

Например, модель может вернуть:

* ошибку;
* перегрузку;
* ограничение;
* временную недоступность.

Если автопереключение включено, плагин попробует другую доступную текстовую модель.

Когда рабочая модель найдена, она может стать новой основной моделью.

---

# 🛟 Переключить на резервную сейчас

В меню моделей есть кнопка:

**🛟 Переключить на резервную сейчас**

Она позволяет вручную перейти на следующую доступную модель.

Это полезно, если текущая модель отвечает плохо или временно работает нестабильно.

# 🎨 Стиль общения

GPT Consultant поддерживает несколько готовых стилей.

---

## 🧠 Адаптивный

Плагин подстраивает тон ответа под покупателя.

Учитываются:

* формальность;
* настроение;
* стиль общения;
* темп переписки.

При этом GPT Consultant старается оставаться профессиональным продавцом.

Это хороший универсальный вариант.

---

## 🙂 Дружелюбный

Ответы становятся более тёплыми и простыми.

Подходит для обычного магазина, где нужен человеческий и ненавязчивый стиль общения.

---

## 🤝 Деловой

Более официальный режим.

GPT Consultant:

* обращается на «Вы»;
* пишет спокойно;
* не использует сленг;
* старается отвечать максимально ясно.

Подойдёт для более серьёзных товаров и услуг.

---

## 🔥 Молодёжный

Ответы становятся:

* короче;
* энергичнее;
* менее официальными.

Допускается умеренный современный сленг.

Если покупатель жалуется или возникает серьёзная проблема, GPT Consultant должен переходить на нормальный серьёзный тон.

---

## ✨ Премиальный

Более сдержанный и аккуратный стиль.

Ответы формируются в формате персонального менеджера:

* спокойно;
* уверенно;
* без лишнего сленга;
* без дешёвого пафоса.

---

## 🎭 Игривый

Для позитивного общения допускается лёгкий юмор.

При этом GPT Consultant не должен шутить:

* над покупателем;
* над жалобой;
* над ошибкой;
* над проблемой с заказом.

---

# 🧠 Как AI принимает решение

Упрощённо GPT Consultant передаёт модели:

* новый вопрос покупателя;
* описание лота;
* название товара;
* цену;
* последние сообщения чата.

После этого модель определяет:

```text
answer
```

— нужно ответить;

```text
internet
```

— нужны внешние данные;

или:

```text
silence
```

— лучше ничего не отправлять.

Режим `silence` используется прежде всего во **«Всемогущем»** режиме.

Например, плагин может промолчать на:

* бессодержательный emoji;
* повторное сообщение;
* сообщение продавца;
* техническое сообщение;
* простую благодарность после завершённого разговора.

---

# 🔄 Что происходит при интернет-поиске

Если AI решил, что нужен интернет:

1. GPT Consultant формирует поисковый запрос;
2. выполняет внешний поиск;
3. получает несколько результатов;
4. передаёт найденные фрагменты обратно AI;
5. модель повторно формирует решение;
6. покупателю отправляется итоговый ответ.

При этом найденные страницы используются только как справочная информация.

GPT Consultant не должен выполнять инструкции, которые случайно находятся внутри найденных веб-страниц.

---

# 🕐 Ограничение частоты ответов

У плагина есть небольшая внутренняя задержка между обработками сообщений.

По умолчанию она составляет около:

```text
2 секунд
```

Это помогает не запускать несколько AI-запросов подряд из одного чата слишком быстро.

---

# 🔐 Какие данные отправляются AI

Важно понимать, как работает AI-плагин.

Для формирования ответа во внешний AI API могут отправляться данные, необходимые для консультации:

* вопрос покупателя;
* часть истории чата;
* название товара;
* описание товара;
* цена.

Если используется интернет-поиск, поисковый запрос также отправляется внешнему поисковому сервису.

Поэтому не используйте GPT Consultant для передачи секретных или чувствительных данных, которые не должны попадать во внешние сервисы.

# 📜 Логи

GPT Consultant ведёт подробный журнал работы.

В логах фиксируются:

* входящее сообщение;
* выбранный режим;
* использованная модель;
* решение ответить или промолчать;
* источник информации;
* краткая причина решения;
* итоговый ответ;
* ошибки AI;
* ошибки интернет-поиска.

В меню можно:

* обновить отображение логов;
* скачать полный TXT-файл.

# 💾 Резервная копия

GPT Consultant может создать резервную копию настроек.

В неё входят:

* основные настройки;
* API-конфигурация;
* выбранный режим;
* модель;
* стиль;
* сохранённое состояние чатов.

Резервную копию лучше создавать перед:

* обновлением;
* экспериментами с настройками;
* переносом плагина.

> ⚠️ Резервная копия может содержать чувствительные настройки, включая API-ключ.
>
> Не публикуйте её в открытом доступе.

# ⬆️ Обновление плагина

GPT Consultant поддерживает два варианта обновления.

---

## 📥 Обновить локально

Откройте:

**⬆️ Обновить плагин → 📥 Обновить локально**

После этого отправьте новый `.py`-файл.

Перед заменой GPT Consultant:

1. проверяет файл;
2. проверяет UUID плагина;
3. проверяет версию;

5. создаёт резервные копии.

---

# 🌐 Проверить GitHub

Второй вариант:

**🌐 Проверить GitHub**

Плагин проверяет официальную raw-ссылку GitHub.

Если там есть более новая версия, её можно установить.

---

# 🗑 Удаление

Из главного меню можно удалить GPT Consultant.

Перед удалением появляется отдельное подтверждение.

При подтверждении могут быть удалены:

* файл плагина;
* настройки;
* логи.

После удаления рекомендуется выполнить:

```text
/restart
```

Если настройки могут понадобиться позже, сначала создайте резервную копию.


---

```text
Привет, можно оплатить сейчас?
```

GPT Consultant самостоятельно определяет, стоит ли ответить.

Никакая команда `/qa` не требуется.

---

Проверьте по порядку:

1. включён ли плагин;
2. добавлен ли API-ключ;
3. доступна ли выбранная модель;
4. если используется Обычный или Эксперт — правильно ли покупатель написал команду;
5. есть ли вопрос после команды;
6. не используется ли команда в режиме Всемогущий;
7. не попало ли сообщение под внутренний cooldown;
8. включён ли интернет, если вопрос требует внешних данных;
9. работает ли API IO Intelligence;
10. что написано в логах.
